# Clawd 桌面宠物

一个常驻桌面的 Clawd（Claude Code 吉祥物）。透明窗口、置顶，Clawd 以外的透明区域可以点穿到桌面。

## 运行

```bash
npm install
npm start
```

测试某个动作时，可以让它启动后直接播放该动作，并关闭随机动作：

```powershell
$env:CLAWD_ACTION = "flag"; npm start
```

## 打包成软件

```bash
npm run package
```

生成的 `Clawd-win32-x64` 文件夹（在项目旁边的 `clawd-dist` 里）就是完整的软件，双击其中的 `Clawd.exe` 即可运行，不需要安装 Node。程序只允许同时运行一只 Clawd；再次双击快捷方式会重建一个全新的 Clawd 窗口（万一它卡住或消失，双击一下就好）。页面崩溃或 20 秒没有心跳时也会自动重建，电脑唤醒、解锁、换显示器后会强制重绘。任务栏右下角的托盘图标可以把它叫回来、重新加载或退出。

## 操作

- **拖动**：按住 Clawd 拖到任意位置，拖动时它会悬空晃腿
- **单击（捉弄它）**：不管它正在做什么，都会立刻被打断，播放一整套反应：受击（眼睛变成 > <，被压扁、抖动、弹开）→ 弹起来 → 落地 → 晕倒（X X 眼、身体歪倒、头上绕星星）→ 甩甩头恢复
  - 可以连续点击：每次点击都从头重播。1.5 秒内连点会累积连击（最多 5 级），跳得更高、晕得更久、音调更高
  - 每一段都有音效（Web Audio 实时合成，没有音频文件），可以在右键菜单里关闭“声音”
  - 右键菜单勾选 **挨打要立正（不躲闪）** 后，Clawd 挨打时原地立正：不会被弹开、不会跳走、不会歪倒，只缩一下；连击 3 次以上会站着冒星星
- **跟随鼠标**：右键菜单勾选后，Clawd 会一路小跑追着光标（屏幕任何位置都行），停在光标旁边，眼睛盯着它看。跟随时暂停随机动作，点击和拖动照常可用
- **全屏时自动隐藏**：前台程序全屏（游戏、全屏视频）时 Clawd 自动隐藏并暂停（不播放动作和声音），退出全屏后回来。由 `fullscreen.js` 每秒检测一次前台窗口（铺满整个显示器且没有标题栏才算全屏，最大化的普通窗口不算）。可在右键菜单关闭
- **右键**：菜单里可以手动播放任意动作（装扮动作在“装扮动作”子菜单里）、开关自动随机动作、开关声音、开关“挨打要立正”、开关“跟随鼠标”、让它回到右下角、退出

## 造型比例

按官方 12×8 像素网格（来自 ClawdMoji 从官方 logo 还原的 `ART`）：身体 8×6 格，手臂在第 2–3 行、各伸出身体 2 格，4 条腿在第 2、4、7、9 列。腿是全宽的，一直延伸到身体后面，并按身体底边实时裁切，所以着地时身体怎么倾斜、抬起、压扁，腿都整条接在身体上。腾空和摔倒（跳跃翻滚、被打飞、晕倒、太空漫步）时则整个角色连腿一起转，腿从胯部晃动。

## 像素渲染

Clawd 显示出来的样子全部经过 `renderer/pixelate.js` 的像素化渲染：

- 一个"美术像素"= 官方 12×8 图里一个大像素的 1/3（屏幕上 4 px）。每秒 12 帧，把当前动作画到小画布上，先关掉抗锯齿放大 4 倍绘制，再取每个格子正中心的颜色，并对齐到 Clawd 的调色板。所以每个像素都是纯色，没有半透明或模糊的边。
- 小角度倾斜会被换成"斜推"（上下边保持水平，侧边一级级错开），整 90° 的旋转保持真正的旋转（比如空翻是 4 格分帧）。眼睛等五官在斜推时保持方块。
- 窗口移动（散步、滑板、跟随鼠标）也按同样的节拍、以整像素为单位一格一格地走。
- 原来的矢量骨架仍然在，但完全透明，只负责驱动动画和判断鼠标有没有点中 Clawd。

### 装扮动作

参考 Anthropic 官方发布的 Clawd 插画绘制，配件和道具都刻意画得比较大（比如比 Clawd 还高的大铁锤、比全身还宽的牛仔帽），动作幅度也放大。配件都是 `renderer/costumes.js` 里用字符画定义的像素图，挂在身体骨架上，跟着身体一起动。

| 名称 | 装扮 | 动作 |
|---|---|---|
| `music` 听歌 | 耳机 | 眯眼跟着节奏摇头，飘音符，配一段 8-bit 旋律 |
| `typing` 敲代码 | 耳机 + 侧边小书桌 | 弹出桌子和显示器、从身后抽出键盘，侧身噼里啪啦敲字，屏幕上一行行出代码；敲完伸懒腰，把键盘推回身后、桌子折叠收起 |
| `skate` 滑板 | 滑板 | 蹬两下滑过屏幕，最后跳一下（ollie） |
| `detective` 侦探 | 礼帽 + 放大镜 | 拿放大镜扫视，发现线索冒出“!” |
| `builder` 施工 | 安全帽 + 锤子 | 抡锤敲 4 下，冒火花 |
| `chef` 做饭 | 厨师帽 + 锅铲 | 颠锅翻煎饼 3 次，滋滋声 |
| `cowboy` 牛仔 | 牛仔帽 + 套索 | 头顶甩套索，扔出去，压帽檐 |
| `wizard` 魔法 | 巫师帽 + 魔杖 | 挥魔杖 3 次，炸出星光 |
| `astronaut` 太空漫步 | 宇航头盔 | 失重飘起、慢慢转、落地 |
| `party` 庆祝 | 头顶蜡烛 | 蜡烛摇曳，蹦两下放烟花 |
| `cool` 戴墨镜 | 像素墨镜 | 墨镜从天而降，酷酷地点头 |

想加新装扮：在 `SPRITES` 里画一张字符画（每个字母对应 `PAL` 里的一种颜色，`.` 表示透明），再在 `costumeActions` 里写动作。

动作之间每隔 6–14 秒随机挑一个，权重写在每个动作的 `weight` 里；点击反应 `poke` 的权重是 0，只能通过点击或右键菜单触发。

## 添加新动作

全部写在 `renderer/pet.js` 的 `actions` 里。每个动作是：

```js
myAction: {
  label: '菜单里显示的名字',
  weight: 1,          // 随机被选中的权重，0 = 只能手动触发
  svg: 'walk',        // 用哪张 SVG：walk / flag / gym / stomp，或你新加的
  run({ b }) {        // 同步返回一个有限长度的 gsap.timeline()；b 是窗口位置（用于移动窗口）
    const r = svgs.walk.rig; // body、eyes、legs、hands、group 等部件
    return gsap.timeline().to(r.body, { y: -5, duration: 0.2, yoyo: true, repeat: 3 });
  },
},
```

注意：`run()` 不能写成 `async`。GSAP 的时间轴本身带有 `then` 方法，从 async 函数里返回它，会一直等到动画播完，导致程序错过结束信号、卡住不动。

- 补间类动作：直接操作 `svgs.walk.rig` 里的部件，结束后会自动复位。
- 逐帧类动作：把新的 SVG 放进 `assets/raw/`，在 `SVG_FILES` 里登记，在 `buildRigs()` 里取出帧（每帧一个 `<g>`），再用 `tl.call(showFrame, [frames, i], 时间)` 排时间轴。
- 要让 Clawd 在屏幕上移动，参考 `walk` 里的 `moveWindow()`。

## 素材来源

`assets/raw/` 中的 SVG 取自 Ayotomiwa Wale-Durojaye 的演示页 [ayotomcs.me/claude-mascot](https://ayotomcs.me/claude-mascot)，对应 Codrops 文章 [Reverse-Engineering Claude AI's Mascot Animations with SVG and GSAP](https://tympanus.net/codrops/2026/05/05/reverse-engineering-claude-ais-mascot-animations-with-svg-and-gsap/)。补间参数（倾斜、跳跃、挥旗摆动、健身节奏、彩带轨迹）也来自这篇文章。
